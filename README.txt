
# M-SEARCH Scanner Tool

## How to Run

1. Make sure you have Python 3 installed.
2. Install Flask if not already installed:
   pip install flask
3. Run the script:
   python app.py
4. Open your browser and go to:
   http://localhost:8080
5. Login with password: kader11000

## Files
- app.py: Main Flask web scanner
- payloads.json: Preset payloads
